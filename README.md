# Actividad evaluativa hito  1 - Machine Learning 2

Este repositorio contiene el desarrollo de la Actividad 1 del curso de Machine Learning, enfocado en la implementación de técnicas de clasificación para detección de fraude (o el tema que estés trabajando).

Estructura del Proyecto

- `datos/`: Archivos de datos utilizados (CSV, Excel, etc.)
- `notebooks/`: Cuadernos de Jupyter con el análisis y el modelo
- `modelo/`: Modelos entrenados y exportados (si aplica)
- `README.md`: Información del proyecto

Contenido

- Carga y preprocesamiento de datos
- Análisis exploratorio
- Selección y entrenamiento de modelos
- Evaluación con métricas (matriz de confusión, ROC, etc.)
- Conclusiones del experimento

Tecnologías

- Python
- Pandas
- Scikit-learn
- Matplotlib / Seaborn
- Jupyter Notebook
